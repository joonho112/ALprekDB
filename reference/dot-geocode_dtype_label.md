# Detect R dtype label for a column (character \| numeric \| logical \| other)

Detect R dtype label for a column (character \| numeric \| logical \|
other)

## Usage

``` r
.geocode_dtype_label(v)
```

## Arguments

- v:

  A column vector.

## Value

One of `"character"`, `"numeric"`, `"logical"`, `"date"`, `"integer"`,
`"factor"`, `"other"`.
