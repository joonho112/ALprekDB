# Load Melissa ERRORCODE Meaning Table

Returns the 17-row reference table of Melissa GE-/AE- family error codes
(severity, meaning, public source). All 17 codes were unobserved (100%
NA) in the v0.8.0 input but are catalogued here so future deliveries
that surface ERRORCODE values can be decoded without further research.

## Usage

``` r
alprek_geocode_errorcode_meaning()
```

## Value

A tibble with 17 rows and columns: `code`, `label`, `severity`,
`meaning`, `observed_in_v080_input`, `observed_n_in_v080`, `source`,
`retrieved_at`.
