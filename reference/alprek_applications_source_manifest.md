# Load Applications Source Manifest

Returns the canonical source manifest mapping ADECE input files to data
kinds, sheets, cycle years, and canonical status.

## Usage

``` r
alprek_applications_source_manifest()
```

## Value

A tibble with columns: `kind`, `filename_pattern`, `sheet`,
`cycle_year`, `canonical_status`, `known_issues`.
